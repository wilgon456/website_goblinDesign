## Highlights

- A goblin-themed hero section with illustration and action links.
- A navigation menu that toggles on smaller screens.
- ScrollReveal animations for the hero, social links and scroll cue.
- Custom CSS with Poppins and Permanent Marker typography.

## Preview locally

```bash
git clone https://github.com/wilgon456/website_goblinDesign.git
cd website_goblinDesign
python3 -m http.server 8000
```

Open **http://localhost:8000**. There is no build step. Fonts, icon sets and ScrollReveal are fetched from external services.

## Customize

| File | Contents |
| --- | --- |
| `index.html` | Navigation, hero, action links and social links |
| `style.css` | Layout and responsive rules |
| `app.js` | Menu toggle and ScrollReveal configuration |
| `main.png` / `pngwing.com.png` | Included image assets |

The action and navigation links are placeholders. This is an independent visual exercise inspired by a game theme, not an official game service. Check the rights for bundled artwork before reusing it elsewhere.
